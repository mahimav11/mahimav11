## 🧭 About me

I build machine learning systems that go past the notebook: trained, wrapped in an API or UI, and deployed so someone can actually use them. My work sits at the intersection of **Data Science, NLP, Computer Vision and IoT**, with a strong focus on problems in **agriculture and accessibility**.

- 🌾 Actively building **OnioRakshak**, my final-year IoT + ML smart onion storage system (IEEE conference paper in progress)
- 🔭 Also exploring: a **memory-augmented chatbot** (Hybrid RAG + Knowledge Graph + LangGraph) and **knee MRI abnormality detection**
- 💼 Completed a Data Science internship at **Celebal Technologies**
- 🎯 Open to Data Science, ML and software engineering roles

## 🚀 Featured projects

### 📊 Data Science core

| Project | What it does | Stack |
|---|---|---|
| **[Customer Churn Prediction](https://github.com/mahimav11/customer_churn_prediction)** | Predicts which customers are likely to leave and explains *why* with SHAP, served through a Flask app | XGBoost · SHAP · Flask |
| **[Sentiment Analysis on Product Reviews](https://github.com/mahimav11/sentiment_analysis_nlp)** | Classifies review sentiment, comparing a TF-IDF baseline against fine-tuned BERT, with a Streamlit demo | TF-IDF · BERT · Streamlit |
| **[Sales Forecasting & BI Dashboard](https://github.com/mahimav11/sales_forecasting_bi)** | Forecasts sales with statistical and additive models and surfaces insights in a Power BI dashboard | Prophet · SARIMA · Power BI |

### 🧠 AI & Deep Learning

| Project | What it does | Stack |
|---|---|---|
| **[SightVoice](https://github.com/mahimav11/sightvoice_assistant)** | Assistive scene reader for the visually impaired: describes an image and speaks the caption aloud; WCAG 2.1-minded UI | PyTorch · ResNet50 + Attention + GRU · gTTS · Streamlit |
| **Memory-Augmented Chatbot** *(in progress)* | Hybrid RAG + Neo4j knowledge graph + long-term memory, with LangGraph tool routing; evaluated on context relevance, correctness and faithfulness | FastAPI · LangGraph · FAISS/Chroma · Neo4j |
| **Knee MRI Abnormality Detection** *(in progress)* | MRNet-style deep learning model for detecting abnormalities in knee MRI scans | Deep Learning · Medical Imaging |

### 🌾 IoT + Full-stack for real-world impact

| Project | What it does | Stack |
|---|---|---|
| **OnioRakshak** *(active development)* | Smart onion storage: ESP32 sensors monitor conditions, ML predicts shelf life and market price, a multilingual RAG chatbot guides farmers, actuators react automatically | ESP32 · ML · FastAPI · React · MongoDB |
| **MilkGuard** | Industrial-IoT system to detect milk adulteration using pH, turbidity and temperature sensors with a live dashboard | Arduino · NodeMCU · Supabase · React + Vite |
| **Farmer E-Diary** | Bilingual (Marathi/English) web app for farmers to track dairy, flour mill, onion sales, vet/feed, medical and diesel records | Firebase · SQLite · JavaScript |
| **SmartFarm** | Deployed and customized an open-source AI agriculture platform: crop and fertilizer recommendation, plant disease detection, weather | Random Forest · CNN · Streamlit · Firebase Auth |
